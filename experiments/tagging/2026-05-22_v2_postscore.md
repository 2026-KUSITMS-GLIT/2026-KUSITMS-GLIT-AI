| --- | ---: | ---: |
| 발견·분석 | 85% | 80% |
| 협업·조율 | 72% | 72% |
| 기획·실행 | 68% | 77% |
| 성찰·성장 | 56% | 69% |
| 문제해결·개선 | 44% | 58% |

문제해결·개선은 표본 6 → 9건으로 늘면서 1차의 58% (rate limit 으로 D-PS 3건 빠진
상태) 보다 더 낮은 44% 가 나옴. 새로 측정된 D-PS 3건 (각 1/2) + DS-PS-01 의 0/2 가
영향. 카테고리 자체의 어려움 (문제 정의·해결 활동의 다양성) 이 패턴인지 v3 측정에서
재확인 필요.

### 6. 길이별: 중간 길이가 가장 약함

| 길이 | 2차 must | 1차 must |
| --- | ---: | ---: |
| 짧음 | 69% | 70% |
| 중간 | 59% | 73% |
| 긺 | 69% | 75% |

중간 길이가 1차 73% → 2차 59% 로 가장 떨어졌다. 1차에서 보였던 "긴 본문이 약간 더
좋다" 패턴은 재현 안 됨. 결국 길이별 편차도 ±10%p 출렁이는 측정 노이즈에 묻힌다.

### 7. 직군 모호 케이스: must 0% 그대로, accept 약간 개선

| 케이스 | must | accept (1차 → 2차) |
| --- | --- | --- |
| P-PA-04 | 0/2 (그대로) | 1/3 → 1/3 |
| DS-DA-04 | 0/2 (그대로) | 2/3 → 3/4 |

DS-DA-04 의 accept 회수는 `#산출물전달` 흡수로 직접 개선. 다만 must 0% 는 두 케이스
모두 그대로. 가중치 신호가 정답에 역행하는 구조라 fixture 흡수로는 안 풀린다.

### 8. corrective 1건은 표면적 원인 미상

P-GR-02 만 corrective (1차의 P-PS-01·D-DA-01·D-PA-03 셋과는 다른 케이스). 재시도로
회복했고 metric 영향 없음. corrective 발생 패턴 자체가 비결정적이라는 신호로도 읽힘.

### 9. 비용·지연 약간 개선

| 항목 | 1차 | 2차 | 변화 |
| --- | ---: | ---: | ---: |
| 평균 응답시간 | 2,228ms | 1,628ms | -600ms |
| 평균 입력토큰 | 2,289 | 2,175 | -114 |
| 1건 비용 | $0.0026 | $0.0025 | 동일 수준 |

LLM_ERR 빠진 평균 + corrective 감소 영향. 절대 측정 시간은 sleep 으로 100초 늘었지만
케이스 1건 비용은 오히려 약간 감소.

## 결정

1. **sleep 2초 표준화 유지.** LLM_ERR 0건 보장으로 측정 신뢰도 확실히 개선. 측정 시간
   ~100초 추가는 수용 가능한 비용.

2. **fixture accept 확장 효과는 v3 측정 후 재평가.** case A 13건 흡수 metric 변화는
   미미했지만 누적 측정 평균에서는 더 안정적으로 보일 가능성이 있다. 단일 측정으로
   fixture 변경의 효과를 결론짓지 않는다.

3. **v3 진입 (후보 7~10 + 점수 격차 5/2/1 + tie-break) 우선순위 1.** 이번 측정에서
   must 떨어진 일부는 LLM 후보 단계에서 정답이 빠진 경우. 후보 갯수 확장이 must 와
   accept 둘 다에서 lever 가 될 가능성.

4. **측정 protocol 검토: 같은 variant 2~3회 평균.** must ±5~7%p 변동이 LLM 비결정성
   에서 오는 것 이번 측정으로 확인. v3 비교 측정도 같은 노이즈에 묻힐 위험이 있어서,
   variant 당 2~3회 돌려 평균 내는 protocol 이 의미 있어 보인다. 비용은 2~3배지만
   진짜 변화 vs 노이즈 분리에 필요.

5. **직군 모호 must 0% 는 가장 큰 단일 약점 유지.** fixture 흡수로 안 풀리고 가중치
   후처리도 못 풀음. v3 의 tie-break (LLM 응답 순서 약가중) 가 일부 도움 될 수 있을지
   측정으로만 확인 가능. 그 결과에 따라 v4 별도 보강 로직 우선순위 결정.

6. **문제해결·개선 카테고리 약함은 패턴 의심.** 1차 (58%, 표본 6) → 2차 (44%, 표본
   9). 표본 늘면서 더 떨어졌다는 건 카테고리 특성일 가능성. v3 측정에서 한 번 더
   보고 fixture 차원 점검 필요할 수도.
